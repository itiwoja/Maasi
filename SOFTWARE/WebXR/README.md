# Maasi WebXR 操作練習

Meta Quest 3のQuest Browserで、Maasiスピンコーターの操作手順を練習するWebXR試作です。PCブラウザーでも同じ手順を操作できます。

## 公開版（Cloudflare Pages）

**https://maasi-webxr-training.pages.dev/**

Quest 3のQuest BrowserでこのURLを開き、**ENTER VR** を選択してください。公開版は有効なHTTPS証明書で配信しているため、開発PCとの同一ネットワーク接続や開発用証明書の確認は不要です。PCではマウスで操作できます。

## Cloudflare Pagesへの再デプロイ

`maasi-webxr-training` はDirect UploadのPagesプロジェクトです。本番ブランチは `main`、ビルド出力は `dist/` です。設定は `wrangler.jsonc` に保存しています。

このディレクトリで実行してください。

```sh
npm ci
npx wrangler whoami
npm run deploy
```

認証していない場合は `npx wrangler login` を先に実行してください。使用するアカウントにはCloudflare Pagesの編集権限が必要です。複数アカウントを使う場合は `CLOUDFLARE_ACCOUNT_ID` で対象アカウントを指定してください。

`npm run deploy` はTypeScriptチェック・Viteビルドを実行し、ローカルの成果物を本番にアップロードします。Gitへのpushによる自動デプロイは設定していません。作業中のソースもデプロイでき、`--commit-dirty=true` によりその旨をデプロイ情報に記録します。

参考：[Cloudflare Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)

## 起動

Node.js 22.12以降（または20.19以降）が必要です。このディレクトリで実行してください。

```sh
npm install
npm run dev
```

表示されたHTTPSのURLをPCで開きます。Quest 3はPCと同じネットワークに接続し、Quest Browserで `https://<PCのLAN IP>:5173` を開いて **ENTER VR** を選択してください。5173が使用中の場合は別のポートになるため、ターミナルに表示されたポート番号に合わせてください。開発サーバーには自己署名証明書を使うため、初回に証明書の確認が表示されます。VRボタンが出ない場合は、HTTPSで開いているか、証明書の確認を終えているかを確認してください。

LAN接続が利用できない場合は、USBデバッグを有効にしたQuestをPCにつなぎ、ADBで `adb reverse tcp:5173 tcp:5173` を実行すると、Quest Browserから `https://localhost:5173` でアクセスできます。

公開する場合は `npm run build` で生成される `dist/` をHTTPSの静的ホスティングに配置します。既存の3MFファイルはViteによってビルド成果物に含まれます。公開環境には有効な証明書を使用してください。

## 操作

- **Quest 3**：左右のコントローラーのレーザーで装置・試料・ピペット、または操作パネルのボタンを狙い、トリガーで選択。
- **作業台の位置合わせ**：左スティックを押し込むと、現在向いている方向の正面へ作業台を合わせます。VR開始時も自動で位置合わせします。着席時はQuestの床高さ設定に合わせて調整してください。
- **PC**：ドラッグで視点移動、ホイールで拡大、対象をクリック。右側のHTML操作ボタンも使えます。
- 灰色の操作を選ぶと、その操作を行えない理由を表示します。
- VR内のパネルからも条件変更、操作、リセットができます。

## 手順・やり方・解説の表示

PCでは右側の「やり方と解説」、VRでは装置の左奥にある「操作ガイド」に表示します。現在の操作に合わせて、次の内容が自動で切り替わります。

- **やり方**：どの対象・ボタンを選ぶか、操作後に何が起こるか。
- **なぜこの操作？**：操作の目的、装置や液体の動きの説明。
- **できた目印**：次の操作に進んでよい状態の確認。

「全手順」で8ステップを一覧表示、「用語解説」でスピンコーター、試料・ホルダー、RPM、START / COAT / STOP、液膜表示の意味を確認できます。「前の説明」「次の説明」は練習の進捗を変えずに説明を読み返す操作です。「現在の操作」を選ぶと、自動追従に戻ります。

Questではガイドのボタンもレーザーとトリガーで選択します。PC画面にはコントローラーとマウスの使い方、運転中には回転数変更・塗布・減速の説明も表示します。

## 練習手順

1. 蓋を開ける。
2. 試料を設置する。
3. 回転数・時間を確認して **START**（600 RPMの滴下用回転）。
4. ピペットを選択して液体を滴下する。
5. 蓋を閉じる。
6. **COAT** で加速・塗布を開始する。
7. 自動減速し、0 RPMになるまで待つ。
8. 蓋を開け、試料を回収する。

**STOP** は現在の回転数から1.5秒かけて減速し、練習を中断します。停止後に滴下から再試行できます。練習完了は、塗布を最後まで終えて停止した後、試料を回収した時点で判定します。

## 再現範囲

### 見た目

リポジトリの `Images/parts.jpg` と `Images/render.png` を参考に、青い3Dプリント筐体、黒い内槽、灰色の蓋フレーム、前面ディスプレイを表現しています。金属のヒンジ・ネジ・ゴム脚・電源ケーブルも追加しています。

実験室には窓、照明器具、収納、薬品瓶、トレー、ビーカーを配置し、天板・床のテクスチャ、環境反射、接地影を加えています。テクスチャはプログラムで生成するため、外部アセットサービスへの接続は不要です。影は起動・部品移動時に更新し、移動中は最大10Hzに抑えています。

ピペットは滴下時に試料上へ移動します。緑色の液体には模式的な厚み・光沢を付けています。前面の小型ディスプレイも運転状態と設定に連動します。実験室や追加部品の一部は、練習用の視覚表現です。

### 動作・形状

- `../../HARDWARE/3mf/` のケース・ベース・容器・蓋・円形ホルダーを読み込みます。部品の配置は試作用で、CADアセンブリの拘束条件を完全再現したものではありません。
- 装置は選択しやすいように実寸の2倍で表示します。
- ファームウェア `../Arduino/maasi/maasi.ino` に合わせ、初期設定を3,000 RPM、30秒、加速3秒、減速1.5秒としています。回転数は300〜8,000 RPM（100刻み）、塗布時間は1〜80秒（1秒刻み）。
- 操作画面はVR向けの日本語パネルで、Nextion画面そのものの複製ではありません。
- 蓋・試料・ピペットは選択すると操作する方式です。手でつかむ操作やハンドトラッキングは未実装です。
- 蓋の開閉制限や操作順のチェックは、このシミュレーターの学習用ルールです。実機ファームウェアのインターロックを表すものではありません。
- 液膜の広がりは模式アニメーションです。膜厚予測・溶媒の物理計算・実機のPID応答は扱っていません。回転数は設定に基づくシミュレーション値です。
- ブラウザーが休止している時間は運転を進めず、戻ってから練習を続けます。

## 検証

```sh
npm test
npm run build
```

運転状態、順序チェック、STOPからの再試行、設定範囲を自動テストします。Quest実機ではVR開始、左右のトリガー、パネルの文字、位置合わせ、全8手順を確認してください。
